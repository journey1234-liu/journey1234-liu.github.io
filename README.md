# journey1234-liu.github.io

Personal GitHub Pages repository, currently hosting **two independent static
sites**:

| Site | Source | Deployed at | Notes |
|---|---|---|---|
| Personal homepage | `sites/homepage/` | `/` | hand-written HTML/CSS/JS; build substitutes cross-site links and analytics config |
| ATM26 Challenge site | `sites/atm26/` | `/atm26/` | Vite + TypeScript SPA; see its [README](sites/atm26/README.md) |

The two sites share no files: `.github/workflows/deploy.yml` builds each one on
its own and assembles them into a single Pages artifact. Either site can
therefore be extracted into its own repository without touching the other — the
ATM26 site documents that recipe in
[`sites/atm26/README.md`](sites/atm26/README.md#standalone-repository).

## Layout

```text
.
├── .github/workflows/deploy.yml   # builds both sites, deploys to Pages
├── sites/
│   ├── homepage/
│   │   ├── index.html  styles.css  script.js
│   │   ├── data/  pages/  assets/
│   │   ├── tools/                  # GoatCounter snapshot fetch + tests
│   │   ├── site.config.json       # atm26Url, goatcounterCode
│   │   └── build.mjs              # substitutes __ATM26_URL__, writes the deploy dir
│   └── atm26/                     # self-contained Vite site (src/ tests/ public/ tools/)
└── README.md
```

## Local development

```bash
# Personal homepage: build into a directory, then serve it
node sites/homepage/build.mjs --out /tmp/homepage
python3 -m http.server -d /tmp/homepage 8080

# ATM26 site
cd sites/atm26 && npm ci && npm run dev
```

## Cross-site links

`index.html` and `data/news.json` carry the token `__ATM26_URL__`, which
`build.mjs` replaces with `atm26Url` from `sites/homepage/site.config.json`. To
move the ATM26 site to another URL or domain, change that one value (plus the
ATM26 site's own base path); no HTML edit is needed. The build fails when a
token survives, so a placeholder can never be deployed by accident.

## Visitor statistics

The homepage shows a visit total and a country/region breakdown — deliberately
without a world map. The numbers come from
[GoatCounter](https://www.goatcounter.com/), which is cookie-free and does not
store IP addresses. The browser loads GoatCounter's `count.js` only when
`goatcounterCode` is set, and reads an aggregate snapshot (`data/visits.json`)
so the API token never reaches the browser.

One-time setup:

1. The site is
   [`journey1234-liu.goatcounter.com`](https://journey1234-liu.goatcounter.com/);
   `goatcounterCode` in `sites/homepage/site.config.json` points at it. To use a
   different GoatCounter site, change that one value — an empty code removes the
   tracking snippet entirely, and a malformed one fails the build.
2. Create an API token with the stats/read permission in GoatCounter
   (`[username] → API`) and add it as the repository secret
   `GOATCOUNTER_API_TOKEN`.
3. Push. Deploys start counting visits immediately; the deploy job writes
   `deploy/data/visits.json` and the daily scheduled run refreshes it. Until the
   token secret exists, the section stays hidden and the build still succeeds.
   To refresh immediately, run the workflow manually
   (Actions → Deploy sites to GitHub Pages → Run workflow).

To refresh the snapshot locally:

```bash
cd sites/homepage
GOATCOUNTER_API_TOKEN=... node tools/fetch_visits.mjs --out /tmp/visits.json
node --test tools/fetch_visits.test.mjs
```

## Deployment

Push to `master`: GitHub Actions builds the homepage, runs the homepage and
ATM26 test suites, builds the ATM26 site, assembles `deploy/` (`/` = homepage,
`/atm26/` = ATM26 site), and publishes it. A daily schedule rebuilds the same
artifact so visitor statistics stay fresh. GitHub Pages must use **GitHub
Actions** as its source (Settings → Pages).

The ATM26 leaderboard data (`sites/atm26/public/data/leaderboard.json`) is
regenerated by an organizer-side publisher on the evaluation host, which commits
to this repository and thereby triggers the deployment above.
