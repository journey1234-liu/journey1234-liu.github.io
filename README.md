# journey1234-liu.github.io

Personal GitHub Pages repository, currently hosting **two independent static
sites**:

| Site | Source | Deployed at | Notes |
|---|---|---|---|
| Personal homepage | `sites/homepage/` | `/` | hand-written HTML/CSS/JS; build only substitutes cross-site links |
| ATM26 Challenge site | `sites/atm26/` | `/atm26/` | Vite + TypeScript SPA; see its [README](sites/atm26/README.md) |

The two sites share no files: `.github/workflows/deploy.yml` builds each one on
its own and assembles them into a single Pages artifact. Either site can
therefore be extracted into its own repository without touching the other — the
ATM26 site documents that recipe in
[`sites/atm26/README.md`](sites/atm26/README.md#standalone-repository).

## Layout

```text
.
├── .github/workflows/deploy.yml   # builds both sites, deploys to Pages
├── sites/
│   ├── homepage/
│   │   ├── index.html  styles.css  script.js
│   │   ├── data/  pages/  assets/
│   │   ├── site.config.json       # atm26Url — single source for cross-site links
│   │   └── build.mjs              # substitutes __ATM26_URL__, writes the deploy dir
│   └── atm26/                     # self-contained Vite site (src/ tests/ public/ tools/)
└── README.md
```

## Local development

```bash
# Personal homepage: build into a directory, then serve it
node sites/homepage/build.mjs --out /tmp/homepage
python3 -m http.server -d /tmp/homepage 8080

# ATM26 site
cd sites/atm26 && npm ci && npm run dev
```

## Cross-site links

`index.html` and `data/news.json` carry the token `__ATM26_URL__`, which
`build.mjs` replaces with `atm26Url` from `sites/homepage/site.config.json`. To
move the ATM26 site to another URL or domain, change that one value (plus the
ATM26 site's own base path); no HTML edit is needed. The build fails when a
token survives, so a placeholder can never be deployed by accident.

## Deployment

Push to `master`: GitHub Actions builds the homepage, runs the ATM26 site's
tests and build, assembles `deploy/` (`/` = homepage, `/atm26/` = ATM26 site),
and publishes it. GitHub Pages must use **GitHub Actions** as its source
(Settings → Pages).

The ATM26 leaderboard data (`sites/atm26/public/data/leaderboard.json`) is
regenerated by an organizer-side publisher on the evaluation host, which commits
to this repository and thereby triggers the deployment above.
